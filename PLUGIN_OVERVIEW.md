## What you get

Office Viewer opens spreadsheets in BB's side panel: `.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.ods`, `.csv` and `.tsv`, from chat links, the file picker and `bb thread open`.

- **A familiar grid** — column letters, row numbers, a frozen first row, right-aligned numbers and merged cells.
- **Big sheets stay fast** — only the visible part is drawn, so thousands of rows scroll smoothly.
- **Values as in Excel** — number and date formats from the file; the cell bar shows the full value and the formula.
- **Search** — find text anywhere in the sheet and step through matches with Enter.
- **Links and copying** — ⌘-click opens URLs from cells; copy any selection with ⌘C.
- **Quote in chat** — select cells, right-click and send them to the agent as a table with the file, sheet and range, plus your comment.
- **Edit without losing formatting** — change `.xlsx` and `.csv` files in place. Only the edited cells are rewritten, so styles, conditional formatting, comments, charts and macros stay exactly as they were.
- **CSV that just works** — comma, semicolon or tab separators; UTF-8 or Windows-1251 text.

## Machine-aware files

A file is read on the machine of the thread, environment or project it came from, whichever device you browse BB on.

## Requirements

BB 0.43 or later. No account, API key or external service. Files up to 30 MB; `.xls`, `.xlsb` and `.ods` open read-only. The interface follows BB's language (English or Russian).
