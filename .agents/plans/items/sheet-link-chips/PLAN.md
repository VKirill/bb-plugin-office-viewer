# Spreadsheet link chips

Goal: a spreadsheet cell whose value is a URL (cell.link != null) renders like BB chat link chips: a rounded pill (border, subtle background, small padding) with a brand icon on the left and the URL shown without scheme (`https://github.com/get-bb/bb` -> `github.com/get-bb/bb`), trailing slash dropped. Same in light and dark theme, using theme tokens (border-border, bg-muted / bg-secondary, text-foreground), not sky-blue underline.

Steps:
1. [x] Create `src/spreadsheet/link-chip.ts`: pure helpers `linkLabel(url)` (strip `http(s)://`, drop a single trailing `/`; return the input unchanged if it is not a URL) and `linkIcon(url)` -> builtin icon name by host: github.com -> Github icon, figma.com -> Figma, notion.so/notion.site -> Notion, slack.com -> Slack, t.me/telegram.org -> Telegram, youtube.com/youtu.be -> Youtube, docs.google.com/drive.google.com -> Google doc/drive, anything else (incl. localhost, 127.0.0.1, [::1]) -> Globe. Use only names present in components/ui/icon.tsx ICON_NAMES (check the exact names there; Icon falls back if unknown). Match host with or without `www.` and subdomains.
2. [x] Create `src/spreadsheet/link-chip.test.ts` (node:test, like sheet.test.ts) covering label stripping and icon mapping including fallback.
3. [x] In `src/spreadsheet/grid.tsx` renderCell: when `cell.link` and the cell is not a bare formula, render inside the cell an inline-flex pill: `<Icon name={linkIcon} className="size-3.5 shrink-0"/>` + truncated label. The pill must fit the 24px row height (e.g. h-5, rounded-md/rounded-full, px-1.5, gap-1, text-xs), truncate long URLs with ellipsis inside the cell width, keep the cell's own background/selection/search highlight classes. Remove the sky underline classes for links. Keep cursor-pointer, the title hint and the Cmd/Ctrl+click open behaviour exactly as now; selecting, editing (double click) and copying the cell still use the raw value.
